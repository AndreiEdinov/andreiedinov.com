RO: поток и выход по пермеату

Выход по пермеату, расход концентрата, средний поток и кратность концентрирования установки обратного осмоса.

Пример значений. Замените их своими данными.

Выход по пермеату—%
Средний поток—л/(м²·ч)
Расход концентрата—м³/ч
Концентрат / питание—×

Формула
Y = Qp / Qf
Qc = Qf − Qp
J = Qp / (N × S)
Cc / Cf = [1 − Y(1 − R)] / (1 − Y)
Источники
  • DuPont FilmTec Reverse Osmosis Membranes Technical Manual, Form No. 45-D01504-en, Rev. 8 (September 2021)
    Определения выхода по пермеату и удельного потока, таблица 27, уравнение 51 для отношения концентраций концентрата и питания.
  • FilmTec, Design Equations and Parameters, Form No. 609-02057-604 (The Dow Chemical Company)
    Более раннее издание тех же уравнений (уравнение 14).
Ограничения и допущения
  • Поток усреднён по всей установке. Головные элементы работают с большим потоком, чем хвостовые.
  • Кратность концентрирования считается по одному среднему задерживанию. Концентрационная поляризация у поверхности мембраны не учитывается.
  • Допустимый поток зависит от источника воды и мембраны. Проверьте проектные пределы в руководстве производителя: в калькулятор они не встроены.
  • Значения в примере только для иллюстрации. Активную площадь берите из паспорта элемента.
